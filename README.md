# ENNAHAL TRAVEL

Responsive French company website, built with HTML, CSS and JavaScript. No build step or dependencies required.

Open `index.html` directly, or preview with `python -m http.server 8080` and visit `http://localhost:8080`.

- `index.html`: company homepage, legal details and a local trip-summary form.
- `privacy.html`: separate privacy policy.
- `styles.css`, `script.js`, `favicon.svg`: shared presentation and functionality.

The trip form generates text locally; it does not send inquiries or make reservations. No telephone, email, fleet, rates or testimonials have been invented. The supplied city (Nador) and registered address (Kénitra) are shown separately; confirm these before publication.

Before going live, add the company's verified contact details. Once the final public domain is known, add absolute canonical URLs, an XML sitemap and social sharing URLs; then submit the sitemap through Google Search Console. Search ranking and indexing cannot be guaranteed. Review the privacy policy against the selected hosting configuration and any future services.

Photography is loaded from Unsplash; typography from Google Fonts. System fonts and a background color act as fallbacks. Deploy all files together to any static web host over HTTPS. This project has not been published.

Visual identity: ruby red, burgundy and warm ivory, with a red-and-gold 3D emblem. The original emerald logo is retained as a source asset.
